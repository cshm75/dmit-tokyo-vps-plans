## Premium 和 Tier 1 的差别：路由决定用途

Premium 贵在回程路由。去程电信走 CN2 GIA 直连、联通走 AS9929、移动走 CMI，三网回程强制走 CN2 GIA（AS4809），教育网也同样落在 CN2 GIA 上。Tier 1 没有做国内路由优化，电信联通走 NTT 双程，偶尔绕美经 Lumen，移动走 CMI。同一个东京机房，两条线对国内用户的实际体验差距就在这一段。

超量策略是第二个分水岭。Pro 系列流量用完直接暂停服务，网站会打不开，得等下个计费周期或额外购买；T1 系列不停机，降速继续跑，WEE 这类入门型号限到 50Mbps，其余型号 100 至 500Mbps。跑个小站、偶尔被爬虫刷流量，T1 这种处理方式更省心；Pro 的停机策略对流量预算要求更严。

按用途分：

- **面向国内用户的站点、API、跨境业务后台**：Pro 线，回国延迟和晚高峰稳定性是买它的唯一理由。
- **日本本地或国际业务、监控节点、备份机、CI/CD**：T1 线，回国绕不绕路无所谓，$6.90/月买个东京 IP 够用。
- **既想要国内快又想大流量**：Pro 的流量单价不便宜，先算清楚月流量再选型号，别默认最低配。
